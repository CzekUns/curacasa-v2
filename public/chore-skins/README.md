# Skin grafiche CuraCasa

Archivio dei set grafici alternativi per le **12 faccende essenziali** (`base-essenziali`). Ogni set contiene 12 WebP e un manifest associativo per `iconKey`.

- **Vintage60** — illustrazione domestica mid-century, 160 × 160.
- **Vintage80** — pop-art/Memphis anni Ottanta, 320 × 320, senza scritte.
- **Ink30** — cartoni monocromatici anni Trenta, 320 × 320, personaggi originali.

**Nota:** i file sono asset di archivio. Non sono integrati nel selettore dell'app: le faccende e le immagini in `/chore-icons` rimangono invariate. **Toon50** è escluso perché la prima prova non era sufficientemente distinta da Ink30 e va rifatta.
